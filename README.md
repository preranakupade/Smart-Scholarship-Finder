# ScholarMatchAI 🎓

ScholarMatchAI is a machine learning-based scholarship recommendation system that helps students discover suitable scholarships based on their eligibility and personal details.

## Features
- **Scholarship Recommendations:** Uses a Random Forest model to recommend the top 3 matching scholarships.
- **Eligibility Filtering:** Filters scholarships based on academic marks, income, category, gender, and other criteria.
- **Role-Based Authentication:** Separate access for students and administrators.
- **Deadline Tracking:** Tracks scholarship deadlines to help students apply on time.
- **Data Visualization:** Presents scholarship-related insights in an easy-to-understand format.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Python
- **Machine Learning:** Random Forest, Scikit-learn
- **Data Processing:** Pandas, NumPy

## How It Works
1. Students enter their personal and academic details.
2. The system filters scholarships according to eligibility criteria.
3. The Random Forest recommendation engine identifies the top 3 matching scholarships.
4. Students can explore scholarship details and track application deadlines.

## Future Enhancements
- Integration with live scholarship databases.
- Email notifications for upcoming deadlines.
- Improved recommendation accuracy with expanded datasets.
